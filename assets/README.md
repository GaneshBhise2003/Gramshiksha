# Assets Directory

This directory contains assets for the Gramshiksha app.

## Required Assets

### Images
Place the following images in the `assets/images/` directory:

1. **onboarding1.png** - Welcome screen background image (1080x1920 recommended)
2. **onboarding2.png** - Interactive learning screen background image (1080x1920 recommended)  
3. **onboarding3.png** - Progress tracking screen background image (1080x1920 recommended)
4. **logo.png** - App logo (512x512 recommended)
5. **student_avatar.png** - Default student avatar image
6. **teacher_avatar.png** - Default teacher avatar image

### Animations
Place Lottie animation files in the `assets/animations/` directory:

1. **celebration.json** - Celebration animation for quiz success
2. **loading.json** - Loading animation
3. **success.json** - Success animation

### Icons
Place custom icon files in the `assets/icons/` directory:

1. **app_icon.png** - App icon for various sizes
2. **achievement_icons/** - Directory for achievement badge icons

## Usage Notes

- All images should be optimized for mobile devices
- Use PNG format for images with transparency
- Use JPG format for background images without transparency
- Lottie animations should be lightweight and optimized
- Follow Material Design guidelines for icons

## Placeholder Images

For development purposes, you can use placeholder images from sources like:
- https://picsum.photos/ (for random images)
- https://via.placeholder.com/ (for placeholder images)
- https://unsplash.com/ (for high-quality stock photos)

Make sure to replace with proper branded images before production release.
